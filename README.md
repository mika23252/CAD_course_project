# CAD Course Project

Учебный CAD-проект, посвящённый разработке трёхмерной модели механического изделия в **SolidWorks**.

## Состав проекта

В репозитории представлены:

- сборочная модель изделия (`Сборка.SLDASM` и связанные файлы);
- отдельные детали в формате SolidWorks (`.SLDPRT`, `.SLDASM`);
- инженерные чертежи деталей и сборки (`.SLDDRW`);
- экспортированные чертежи в PDF и изображения-превью;
- спецификация изделия;
- пояснительный отчёт (`Отчет КП САПР.pdf`).

По именам файлов можно установить, что модель включает корпус, маховик, валы, зубчатое колесо, пружину, втулки, прокладки и стандартные крепёжные элементы. Точный состав и назначение узлов следует сверять по сборочному чертежу и отчёту.

## Используемое ПО и форматы

- **SolidWorks** — создание деталей, сборки и конструкторской документации.
- `.SLDPRT` — деталь SolidWorks.
- `.SLDASM` — сборка SolidWorks.
- `.SLDDRW` — чертёж SolidWorks.
- `.PDF`, `.JPG` — экспортированные документы и изображения.

## Как открыть проект

1. Скачайте репозиторий целиком, сохранив структуру папок.
2. Откройте `Сборка.SLDASM` в SolidWorks.
3. Если SolidWorks сообщит об отсутствующих ссылках, проверьте, что папки `детали` и `чертежи` находятся рядом с файлом сборки и что имена файлов не изменены.
4. Для просмотра документации используйте PDF-файлы в папке `чертежи` и пояснительный отчёт в корне репозитория.

## Примечание

Файлы SolidWorks и PDF перечислены по структуре репозитория GitHub. Их бинарное содержимое не анализировалось в рамках подготовки этого README, поэтому описание назначения изделия намеренно ограничено сведениями из имён файлов и структуры проекта.
